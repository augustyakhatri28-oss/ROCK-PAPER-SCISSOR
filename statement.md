## Problem Statement: Rock, Paper, Scissors Game

The objective of this project is to develop a simple, interactive Rock, Paper, Scissors game using Python in which a user competes against the computer. The game allows the player to choose between Rock, Paper, and Scissors, while the computer randomly selects its move.

The program compares both choices based on the traditional rules of the game to determine the winner of each round. It includes input validation to handle invalid entries and maintains a record of the player's wins and losses.

The game consists of a maximum of three rounds and ends early if the player secures two wins. At the end of the game, the program displays the final scores and announces whether the player has won, lost, or drawn the game.


## Key Features

- User-friendly, menu-driven interface.

- Random computer moves using Python's random module.

- Three-round gameplay with an early stopping condition.

- Input validation to prevent invalid choices.

- Automatic tracking of wins and losses.

- Final result announcement based on game statistics.

## Objective

This project aims to strengthen fundamental Python programming skills, including the use of functions, loops, conditional statements, exception handling, user input, and random number generation through a fun and engaging game.

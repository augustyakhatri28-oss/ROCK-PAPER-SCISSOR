🪨 📄 ✂️ RockPaperScissorPython
Hey welcome to the Rock Paper And Scissor Python GAME!!
I build this project while brushing my python basics . Its basically a minigame we all played while growing up. For me its the best experience to learn and polish my control statement ,loops,taking inputs and use built-in-modules 



🌟 Overview
THE basic game idea was to go beyond the simple code and make things challenging and interesting. Its a full one-v/s-one against computer so that a ideal person who have a basic machine can play in their boredom . Its consist of multiple rounds and different case handling so that the game does not crash


✨ Features

1.Its have a basic number(1-3) input system and handles invalids cases and handle it

2.Its basically a fully randomized game in which computer randomly select one element(rock,paper,scissor)

3.live attempt counting system in which player have idea how much attempts is left (basically offer three rounds/attempts)



🛠️ Technologies Used

Language: Python 3

Modules: random (built-in standard library)

Environment: VS Code & Terminal / PowerShell
